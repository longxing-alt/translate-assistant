# 网页翻译助手(全新独立插件)

一个**从零编写**的轻量翻译插件:无侧边栏、无登录、无学习/会员界面,只有翻译核心。

## 功能

| 功能 | 操作 | 说明 |
|---|---|---|
| **全页沉浸式翻译** | `Ctrl+F` 或 `F2` | 网页文本**直接替换为中文**(再按一次还原);英文、法语、日语等非中文 → 中文 |
| **输入框快速翻译** | 输入内容后连按 3 次空格 | 输入框内容翻译成**英文**并替换 |
| **视频字幕双语** | 自动(YouTube 等) | 英文字幕下方追加中文行(双语显示) |
| **邮件/弹窗/嵌套页面** | 自动 | 覆盖 iframe(about:blank/blob/跨域)、shadow DOM 动态内容 |

- 无需登录、无需设置、无后台界面
- 翻译经 Google 翻译接口(background 请求)
- 支持本地文件页面(需在扩展详情开启"允许访问文件网址")

## 安装

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」→ 选择本目录(`translate-assistant`)
4. 若之前装有 Trancy 修改版,请**禁用**,避免双重翻译

## 文件

- `manifest.json` — MV3 配置(全站注入,含 iframe/shadow 支持)
- `content.js` — 全页翻译、快捷键、三连空格、iframe/shadow 递归广播
- `subtitle.js` — 视频字幕双语
- `background.js` — 翻译请求代理(规避 CORS)与指令广播
- `icons/` — 应用图标
